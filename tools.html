Quick-access scripts for common Windows maintenance tasks.

How to use: Click a button to download the .ps1 script. Right-click the downloaded file → Run with PowerShell. If prompted, choose Run anyway (scripts are unsigned). Administrator rights may be required.

⚠️ Restart your PC?

This will download a script that restarts Windows in 30 seconds after you run it. Save any open work before running the script. You can cancel with shutdown /a in the terminal if needed.
